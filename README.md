# Clip Genius

Quero criar um sistema de clip de video, onde ele não vai ser salvo na nuvem, o cliente vai ter ate o final da seção pra baixar atualizou a pagina cai os clips, ele precisa ter, esse sistema é algo parecido com opus clip, mas não precisa legendar ou algo do tipo, quero so que ele selecione os melhores clips de um video longo e separe mas tenha um estudo e uma analise antes, pra seguir senqucnia estilo de clip de luta, climax, discuções, estudos, apresentações, etc
